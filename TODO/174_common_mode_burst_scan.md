## 1. 作るもの
### A. `tools/scan/burst_scan.C`(ROOT マクロ、既存の tools/scan と同じ流儀)
- 署名: `burst_scan(const char* rawFile, const char* outPrefix, double samplingMHz, Long64_t maxEvents = -1, double kThr = 5.0)`。
  `samplingMHz` は**必須**(169 の方針: 物理パラメータに既定値を持たせない)。µs への換算に使う。
- 入力: tree `raw`、`eventId`、`eventTime`(CoBo の時刻印、そのまま記録)、`adc[N][68][512]/S`(N = 4 × AsAd 数、先頭次元は焼き込まず実ファイルから読む — run_metrics.C と同じ扱い)。
  全セル 0 の ch(部分読み出しの未読 ch)は除く。
- ch の区分: **FPN = 生 ch 11, 22, 45, 56**(AGET ごと)、信号 ch = それ以外。
- 事象ごとの処理:
  1. ch ごとの基線 = その ch の 512 セルの中央値。以後は基線を引いた値。
  2. 共通モード波形: `cmF[b]` = 読めた FPN ch のセル b の中央値、`cmS[b]` = 信号 ch のセル b の中央値(中央値なので数本の信号 ch には引きずられない)。
  3. バーストの検出は `cmF` で行う: 窓幅 W = round(2.0 µs × samplingMHz)(12.5 MHz で 25、25 MHz で 50)の移動 RMS の最大値。
     雑音の基準 σ_ref = 1.4826 × MAD(cmF の全セル)。**最大の移動 RMS > kThr × σ_ref ならバーストあり**。
  4. 記録: バーストの位置(移動 RMS が最大の窓の中心バケット)、振幅(その窓内の cmF の peak-to-peak)、長さ(移動 RMS が閾値を超えるバケット数)、
     周期(その窓内の cmF のゼロ交差の平均間隔 × 2、バケット → µs)、同じ窓での cmS の peak-to-peak(FPN / 信号の比を出すため)。
  5. 信号: 信号 ch の(基線を引いた)値の ch 和の最大バケット = `sigPeak`、その ch 和の総和 = `sigCharge`。
- 出力:
  - `<outPrefix>_burst.root`: tree `burst`(run 番号は分かれば、eventId、eventTime、hasBurst、burstBucket、burstAmpPP、burstLen、burstPeriodUs、cmSigAmpPP、sigPeak、sigCharge、sigmaRef)。
  - `<outPrefix>_burst.json`: 事象数、バーストの割合、burstBucket の分布(ヒスト + **一様性の KS 検定**: 区間 [W/2, 512 − W/2] の一様分布との p 値)、
    周期の中央値と 16/84 % [µs]、振幅の中央値、FPN / 信号の振幅比の中央値、(burstBucket − sigPeak)の分布の中央値と 16/84 %。
  - `<outPrefix>_burst.png`: 2×2(burstBucket のヒスト / burstBucket − sigPeak のヒスト / 周期 [µs] のヒスト / 時刻(eventTime)に対するバースト率)。
- 1 行の要約を標準出力へ(`burst_scan: N events, X % with burst, KS p = …, period median … us`)。

### §3a の実装での逸脱(主対話が採用)
- 発注書の「W(2 µs)窓内で平均を引いたゼロ交差 ≥ 3」は、周期 1.5 µs では窓に交差が 2–3 個しか入らず本物のバーストを落とした((b) 0/300、(c) 1/300 検出 = 発注書の誤り)。
- implementer の対処: **ゼロ交差の数だけ、最大窓を前後に W/2 広げた区間(最大 2W ≈ 4 µs)で、その区間の平均を引いて数える**。振幅・周期・位置・長さは従来どおり W 窓。
  採用理由: 「W 窓で ≥ 2」に緩めると単発の両極性パルスも通る。2W で ≥ 3 は 1.5 周期以上の振動を要求できる。

- 予言(確かめ方): ① 圧力 ↑ で遅れ ∝ p(200 mbar で ≈ 2 倍 = 窓からほぼ出る)② TR の電場で遅れ ∝ 1/E ③ 12.5 MHz のパルサー run では遅れた振動は出ない(イオンが無い)。出ればイオン説は外れ。
