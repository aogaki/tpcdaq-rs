## 主対話の下調べ(2026-11-03)
- **配線**(`macros/channel_map.csv`): 偶数 / 奇数の strip は**別の AGET**に乗る。U = 偶数 AGET 1(36 本)/ 奇数 AGET 2(36)、W = 偶数 AGET 3(46)/ 奇数 AGET 0(46)、V = 偶数 AGET 0(18)+ 1(28)/ 奇数 AGET 2(28)+ 3(18)。V が弱いのは 2 つの AGET が混ざって薄まるためと読める。
- **電子回路の利得**(138 のパルサー、502 ns、`all`・`agets` の振幅中央値): −300 mV で AGET 0 / 1 / 2 / 3 = 993.5 / 1006.9 / 975.2 / 988.2 ADC、−100 mV で 349.8 / 351.8 / 340.8 / 346.6。
  - U: AGET 1 / AGET 2 = **+3.2 %**(観測 +5.8 % の半分)。
  - W: AGET 3 / AGET 0 = **−0.5 〜 −0.9 %**(観測 +4.2 % を説明しない)。
  → 電子回路の利得は U の一部だけ。残り(U ≈ +2.6 %、W ≈ +5 %)は検出器側(pad の並び・strip の容量・入力網)か、模型の pad 応答の差。パルサーはテスト容量から AGET に入れるので、検出器側の差は見えない。
- 次の判断材料になりうる測定: 長い壁 α の飛跡に沿って、偶数 / 奇数 strip の積分電荷の比を AGET の利得で割った残り(電子回路を除いた検出器側の比)。
