# 084 — GEM 信号トリガの特性評価と設計し直し(CFD 遅延の根拠、閾値の記録、turn-on 測定)

**Status: DRAFT**(2026-09-17 起票 Fable。発端 = 083 の副産物: 2026-09-15 run でゲイン +40 % の階段に対しトリガ通過率が
×4.5、CFD の遅延線 5–7 ns。ユーザー「ここはちゃんと出しておきたい。必要な遅延は波高の 75 % あたりまでの時間と考えている」)

## 1. いま分かっていること(データ、083 追記 4)

- トリガ = GEM フォイルの HV → フィルタボックス → NIM **CFD**(遅延線 5–7 ns、閾値未記録)→ TTL → CoBo 外部トリガ。
- 09-15 run のセグメント 1(ゲイン低)は電荷スペクトルの高電荷側の裾が消えた**別の形**(分位比 10 % 1.13 / 50 % 1.38 / 90 % 1.67)、
  レート ×1/4.5。→ トリガが通すイベントの**種類**がゲインで変わる = 効率が 100 % から遠く、形に依存。
- **GEM 電流の持続時間 = トラックの電荷到着の時間幅**(パッドデータから、09-15、10,024 events、v_drift 非依存):

| 量(1 イベント) | 10 % | 中央値 | 90 % | 99 % | 最大 |
|---|---|---|---|---|---|
| 電荷の 10–90 % が届く時間幅 | 2.8 µs | 5.5 µs | 11.1 µs | 14.5 µs | 15.2 µs |
| 電荷の 5–95 % | 3.5 µs | 6.9 µs | 13.1 µs | 16.6 µs | 17.3 µs |

  積分型(フィルタボックスの RC が長い)の GEM 信号なら、**立ち上がり時間 = この時間幅**(3〜15 µs、イベントごとに ×5 ばらつく)。

## 2. CFD の遅延はいくつ要るか(ユーザーの問いへの答え)

- 原理: 比率 f の CFD が振幅非依存になる条件は **t_d ≥ (1 − f) × t_rise**(f = 0.25 なら「75 % に達するまでの時間」 — お考えどおり)。
  ARC 動作(t_d < (1−f) t_rise)は立ち上がり形が一定な速い信号向け。
- 当てはめると **t_d = 0.75 × (3〜15 µs) = 2〜11 µs**。ケーブル遅延 5 ns/m では 400〜2,200 m、NIM CFD の内蔵遅延は ≤ 100 ns。
  → **この信号に CFD は原理的に合わない**(立ち上がりが µs 級で、しかもイベントごとに 5 倍ばらつく)。5–7 ns の遅延では
  零交差の条件が「傾き × 7 ns ≈ f × 振幅」= 傾き(dV/dt)トリガになり、閾値の意味が振幅から外れる(観測と整合)。
- 「定数比」を µs 信号でやるなら**デジタル**(波形デジタイザ上の CFD)しかない。アナログで現実的なのは次の 2 案。

## 3. 案(どちらも「閾値が読める・記録できる」が必須条件)

| 案 | 構成 | トリガ時刻 | 長所 | 短所 / 条件 |
|---|---|---|---|---|
| A 積分 + リーディングエッジ | フィルタボックス出力 → 整形(数 µs)→ LE ディスクリ(閾値低め、記録) | 信号が閾値を超えた時刻 = 振幅依存の time walk(≤ 立ち上がり ≈ 最大 10 µs) | 単純、閾値 = 振幅なので turn-on が電荷で測れる | **SCA 窓に余裕が要る**: 25 MHz(20.5 µs)は 17 µs の最大幅 + 3 µs pre で余裕ゼロ → **12.5 MHz(41 µs)前提** |
| B 微分 + リーディングエッジ | 速い整形(100–200 ns)で「最初に届いた電荷」に反応する LE ディスクリ | 最初の電荷到着(トラック長に依らない) | 窓を詰めて置ける、25 MHz でも可 | 閾値が「電荷到着レート」に対する値になりノイズ限界に近い。現在の CFD が偶然やっていることを、既知の閾値で意図的にやる形 |

いずれも **閾値を記録**(手書きでも可、理想は遠隔読み出しできるプログラマブル判別器 → slowctl で logbook へ)。

## 4. 測ること(次の線源 run、半日)

1. フィルタボックス出力の波形(オシロ、数十イベント): 立ち上がり時間の分布を直接見て §1 の表と照合。
2. **turn-on 曲線**: 閾値 2〜3 点で run し、パッド電荷スペクトルの立ち上がり位置を比較(効率 = 高閾値 / 低閾値の比)。
   α のエネルギーが分布する ¹⁰B 実験では効率のエネルギー依存が要る。
3. トリガ遅れ L の実測(080 B-4 の式 c = (窓 − delay − L)/40 ns。帯位置から自動推定)。
4. 12.5 MHz + delay 3600 の組で窓に収まるか(080 §0)。
