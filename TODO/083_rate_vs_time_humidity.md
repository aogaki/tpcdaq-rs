## 仮説と判別(第 2 弾 — 完了、2026-09-17)

- 仮説 A(ユーザー): **ガス湿度**(H₂O、あるいは O₂)による電子付着 → 信号が小さくなり、外部トリガ閾値を超えるイベントが減る。
  → 判別量 = **イベントあたりの電荷(qview 合計)の時間変化**: 付着なら電荷スペクトルが時間とともに低側へずれ、レート減少は
  閾値で切られた分に一致する。湿度計(Michell Easidew)/ O₂ 計(NTRON)の読みがあれば相関を取る。
- 仮説 B(Fable、消去すべき対抗仮説): **²¹²Pb(T½ 10.64 h)の減衰** — 溶接痕の ²³²Th 系列から出た ²²⁰Rn(thoron、56 s)の
  娘 ²¹²Pb が壁・カソードにプレートアウトしていて、ガス交換/流通が始まって供給が止まり 10.6 h で減る(α は ²¹²Bi/²¹²Po)。
  観測の 12.1 ± 0.8 h は 10.6 h と 2σ 以内。→ 判別: 電荷スペクトルは**変わらず**、数だけ減る。定数 0.014 Hz = 溶接痕直接の α。
- 手順: `graw2root.C+`(09-15、実行中)→ `analyzeUVW.C`(`_uvw.root`: eventId, qview[3])→ 時間(ヘッダ走査の eventId → 秒)と
  結合して「電荷の中央値 vs 時間」「前半/後半の電荷スペクトル」を出す(新 macro `chargeVsTime.C` か rateVsTime に追加)。
- ユーザーに聞くこと: ①run 中のガスは流通か静置か、切替の時刻 ②露点計・O₂ 計の読み(時刻付き)③再起動(1.7 h)で何を変えたか
  ④トリガ源(NIM チェーン)の入力は何の信号か(閾値の効き方に直結)。

## やらないこと

## 結果(第 2 弾: 電荷 vs 時間、2026-09-17、Mac)

- 手順: `graw2root.C+`(09-15、10,027 events → 1.28 GB raw.root)→ `analyzeUVW.C+`(macros/ から実行、`channel_map.csv` 必須。
  定数は 1200 V / 100 mbar の既定のまま — 電荷合計には効かない)→ **`chargeVsTime.C`(新規)** で eventId 順に結合、1 h bin。
- **判別結果**: レートが 0.137 → 0.025 Hz(×1/5.5)に落ちる 45 h の間、**イベント電荷(Σqview)の中央値は 4.5e6 → 5.0e6 ADC
  (+11 %)、16–84 % 帯も動かず、ヒット数中央値 ≈ 18k で一定**。前半 1/4 と後半 1/4 の電荷スペクトルはほぼ重なる(後半が
  わずかに高側)。→ **仮説 A(湿度/O₂ の電子付着で信号が落ちて閾値割れ)は否定**: 付着なら電荷が下がるはずで、逆に上がって
  いる。上がった分(+11 %)は系が乾いていく(付着が減る)か圧・ゲインの変化と読めるが、レート減少とは逆向きで説明にならない。
- **残るのは仮説 B(数だけ減る = 放射性の減衰)**: T½ = 12.1 ± 0.8 h は ²¹²Pb(10.64 h)と整合、定数 0.014 Hz が溶接痕の
  ²³²Th 直接分。再起動前セグメント(0–1.7 h)は電荷中央値 3.2e6 / ヒット 16.5k と別条件(設定違い)。
- 含意: (a) 「バックグラウンド」の大半は溶接痕の thoron 娘のプレートアウト(²¹²Pb)で、**ガス交換・流通の履歴で大きく変わる**
  — 静置後の run 開始直後が最も高い。物理 run の前に十分な流通時間(> 1 日)を置くか、run 中の減衰を織り込む。
  (b) 湿度は少なくともこの run ではレートに効いていない(電荷 +11 % の緩い上昇は別途、露点計の記録と照合する価値あり)。
