### B-3 追記(2026-11-03): 余っている CAEN N1068S / N1168 はトリガ作りに使えるか(ユーザー「誰にも使われていない」、マニュアル = `reference/N1068_rev6.pdf`・`N1168_rev5.pdf`)
- **N1068S(16 ch 分光増幅器 + CFD、単端 50 Ω 入力)= 使える**: 電荷有感プリアンプの出力向け(ポールゼロ 20–2,000 µs の尾)。エネルギー側 = CR-RC⁵ 整形 0.5 / 1 / 2 / 4 µs、利得 2.8–710。タイミング側 = 微分 100 / 500 ns・積分 20 / 80 ns の帯域フィルタ → 30 % CFD(遅延 8–40 ns、ジャンパ)、閾値 0–4,095 mV(1 mV 刻み)、OR 出力(NIM、幅 157–1,825 ns)、多重度トリガ(MUL DISC)。MUX で任意の ch のエネルギー / タイミング波形をオシロへ出せる。**USB / Ethernet / RS485 の ASCII コマンド**(`$BD:00,CMD:SET,CH:0,PAR:THR,VAL:200` 等)で全パラメータを遠隔で設定・読み出し。
  - 今の CFD(遅延 5–7 ns、帯域制限なし = 実質 dV/dt)より**高周波の EM 雑音に強い**見込み: CFD の前に微分 500 ns・積分 80 ns のフィルタ(≈ 0.3–2 MHz の帯域)が入る。ただし µs 整形の LE(A 案)ほどではない。
  - CFD の遅延は「Tdelay = Trise × 0.7」が前提で、µs の立ち上がりには最大 40 ns でも短い = ARC(振幅・立ち上がり補償)側で動く。トリガ(GET は µs の時刻で足りる)には問題ないはずだが、**マニュアルは「合わないと正しく出力しない」と警告** → 実機で確かめる。
  - **A 案(µs 整形 + LE)にも使える**: エネルギー出力(0.5–4 µs、利得は遠隔)→ 外付けの LE 弁別器。
  - 遠隔の閾値設定は B-3 ②(閾値 2–3 点の turn-on 曲線)を制御室からできる。設定は run 開始時に slowctl で読んで記録できる(ただしマニュアル: 動作中に頻繁にアクセスしない — 雑音のため。ポーリングはしない)。
- **N1168(16 ch 高速シンチレータ用、CFD 遅延 1.5–7.5 ns、整形 0.2–0.8 µs)= GEM のトリガには向かない**: PMT・シンチレータ(LaBr3、CLYC の PSD)向けで、CFD の性格は今の速い CFD と同じ。隣の中性子実験の検出器の方が使い道がある。
- 入力の条件: 50 Ω で駆動できること、±4 V 以下、極性はどちらでも。**トリガ用プリアンプの出力は負極性(ユーザー 2026-11-03)→ N1068S は極性をソフトで切り替える(`PAR:POL,VAL:1` = 負、ジャンパ不要)**。残りの確認 = 50 Ω 終端での振幅(−4 V より浅い)と、エネルギー側を使うなら尾の時定数(ポールゼロ 20–2,000 µs)。N1168 は極性がジャンパ。
- 試す順(案): ① MUX でタイミング / エネルギー波形を見る(B-3 ①)② 今の CFD と並べて同じ信号を入れ、10 分ずつのトリガ率とヒット無し事象の割合(189 の指標)③ 遠隔で閾値 3 点(B-3 ②)。
- **接続の確認(2026-11-03、ユーザーの Mac の USB-LAN en11 に 1 対 1、Mac 側 192.168.0.10/24)**: ping 0.5 ms。TCP 23 に ASCII コマンドをそのまま送れば応答(`caen` のログインはメニュー画面用)。1 接続に複数コマンドを詰めると応答が落ちることがある → 1 コマンド 1 接続で読むのが確実。**読み出しだけ、何も変えていない**。
