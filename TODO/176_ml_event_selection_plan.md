## 0. 対象
- PuBe の中性子(173 §2k–2l): ¹⁶O(n,α)¹³C の 2 本、¹²C(n,α)⁹Be、¹²C(n,n')3α、C / O の弾性反跳、ガンマ由来の電子、振動だけの事象(174)、宇宙線、頭切れ。

## 1. 失敗の典型(Opus の整理)
1. シミュレーションで学習 → 実データで崩れる(雑音・振動・利得の揺れ・飽和・頭切れ・死 ch がシミュレーションに無い。分類器が「きれいさ」を目印に覚える)。
2. 実データに正解ラベルが無く、評価がシミュレーション内で閉じる(実データの純度・効率が不明)。
3. 選別が物理量の分布を歪める(E_n・角度)のに気づかない。
4. 想定外の事象を既存のクラスに無理に入れる(振動だけの事象を自信満々に反跳と答える)。

## 2. このプロジェクトの材料
- 実測した応答: 電子回路の応答の核(138、パルサー、peaking 4 点)、拡散(147)、z と 2D の分解能(146 / 148)、ペデスタル・雑音・飽和、ストリップのジオメトリ(TPCReco の .dat)、dE/dx・飛程(TPCReco の SRIM 表)。
- 答えの分かっている実データ: ²²⁸Th の α(run 175 = 106 万事象、線の位置・エネルギー既知 = 168)、パルサー(187–192)、振動だけの事象(174、run 190)。
- 本物の雑音の見本: 粒子のいない窓(ペデスタル run、ヒット無しの事象)。

## 3. 提案する順番(Opus 案、確定は Fable)
1. **デジタイザ**: シミュレーションの飛跡 → 実データと同一形式の生波形(raw ツリー `adc[N][68][512]/S`、SPEC §6.7)。実測の応答の核・拡散・利得 + **実データの空の窓をそのまま重ねる(オーバーレイ)**。
2. **α で答え合わせ(関門)**: ²²⁸Th の α をシミュレーションし run 175 と比較(長さ・電荷・ストリップあたりの波高・パルス幅・ブラッグピークの形)。一致するまで分類器に進まない。
3. **分類器は小さく**: まず物理の量(飛跡の本数・長さ・電荷・dE/dx の縦断面・頂点の形)+ 勾配ブースティング。深層学習は形の判別(2 本 / 1 本など)に絞って足す(入力 = 3 面の strip × time 画像か、ヒットの点群)。
4. **「わからない」の出口**: 想定外は既存クラスに入れずはじく(自己符号化器・埋め込みの距離など)。
5. **人間の目は最終試験**: ユーザーが目で選んだ実データ数百事象は学習に使わず、最後の答え合わせに取っておく。
6. **歪みの測定**: シミュレーションの事象を実データの雑音に埋め込み、E_n・角度・頂点ごとの効率。PuBe のスペクトル(ISO 8529)と比べて選別が分布を歪めないことを確認。
