## 読み
- **240 fC は 120 fC の 1/1.87**(公称 1/2)。ヒット ch 127 → 119、長さ 88 → 84 mm と弱いストリップを少し失うが、**飽和 4.7 % → 0.7 %**、末尾クリップ 21 → 9 %。
- **1 pC は α では使えない**(現状の partial readout + macros の固定閾値 35 ADC / STRIP_Q_MIN 2000 では): hit register を越える ch が 23 本しか無く(ハード側で読まれない)、飛跡 ok 0.9 %。1014 ns でも ok 63 %、長さ 48 mm。1 pC を使うなら `readout: full` + 閾値の見直しが要る(C の話)。
- **揺れは出力振幅に比例する**(= 電子回路のゲインに乗る): 1014 ns で 120 fC → 1 pC の比 59.9 / 7.5 = 8.0(床を差し引くと ≈ 8.5、公称 8.3)、502 ns で 27.9 / 15.5 = 1.8(公称 2)。固定振幅の外来ノイズではない。**ただし電子回路由来か検出器由来かはこれでは決まらない**(入力電荷に比例するものはどちらもゲインに乗る)→ 138 のパルサー核で決める。
- **E の設定(規則: 飽和 event < 2 % の中で最長 peaking とその gain)**: 測った中では **502 ns × 240 fC(run 88 の条件)**。1014 × 240 fC は未測定(1014 × 120 fC の 33.7 % から見て 2 % は厳しい見込み)→ 1 run 追加して確かめる(下)。
