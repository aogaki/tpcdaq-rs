**本物と判定。根拠 4 点:**
1. **Bragg 曲線**: 帯で終わる飛跡の U ストリップ電荷は入口 7,300 → x ≈ −25 で 8,600 → 終点へ急落。貫通飛跡は 4,238 → 5,074 の緩い単調増加で **x = 0 を連続に通過**(死にストリップではない)。
2. **x_end は単一ガウス**(中心 +1、σ ≈ 4 mm)+ 平坦な下地(Rn 系列、≈ 35/ビン)。3D 長 57.4 ± 4.7 mm。幅 4.7 mm は全飛程 388 mm の 1.2 % = α のストラグリングの期待値そのもの。
3. **電荷法と整合**: 残飛程 57 mm → ASTAR で 1.53–1.58 MeV。09-25 の較正(1.16e5 + 4.42e5·E)の予言 8.0–8.1e5 ADC に対し実測ピーク ≈ 8.3e5、平均 7.86e5。
4. **線の同定**: ケージ内に 1 本だけ出るのは ²¹⁶Po(6.78 MeV、388 mm)のときだけ。壁まで d ≈ 333 mm(x_src ≈ −386)なら ²¹²Bi(325)は届かず、²²⁰Rn(345)は x ≈ −41(入口帯の中、長さ 12 mm で 10 ヒット/ view の下限未満 → 再構成されない)、²¹²Po(586)は貫通。
   ²²⁰Rn や ²¹²Bi が x = 0 に来る距離なら 2〜3 本のピークが並ぶはずで、観測と合わない。貫通/停止 = 5208/6457 = 0.81(分岐比 0.64 + Rn 雲の寄与)。
- 線源を −386 と置くと生成時エネルギーは 6.88 MeV、σ 0.109 MeV(**FWHM 3.7 %**)= 飛程法の分解能(距離を 3 mm 動かせば 6.78 に合う。距離の実測値が要る)。
- 電荷分布は σ ≈ 11 %(低側に尾)。残エネルギー自体がストラグリングで ±5.5 % 揺れるので、電荷法固有は ≈ 9–10 %(長さとの相関で補正可能、未実施)。
- 注意: 貫通飛跡の dE/dx 比(出口/入口)は 09-25 が 1.42(期待 1.65)、今回 1.20(期待 1.29)と**毎回期待より小さい** = Rn 雲由来の高エネルギー α の混入で薄まる。比から線源距離を出すと近めに偏る(093 追記 3 の −430 もこれ)。
