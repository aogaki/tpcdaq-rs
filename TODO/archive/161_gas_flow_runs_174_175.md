### 時間推移(175、1 時間ビン、統計精度 ±0.5 %)

- ヒット ch 121 → 120 → 119(±1)。帯位置 first 75 / last 98 cell、パルス幅 56 cell、電荷重心時刻 90 cell: **不変 = ドリフト速度・拡散は変わらない**。

### 判定
1. 流量 100 → 50 ml/min で **総電荷 −3.5 %、dEdx −4 %**(ゲインまたは収集効率の低下)、数時間で新しい平衡に落ち着き、その後 60 h 安定。飛跡の質(ok、長さ、dip)は不変。
2. HV は無関係。ドリフト速度・拡散が不変なのでガス組成の大きな変化ではなく、不純物の平衡か密度のわずかな変化。温度・圧力の記録が無いので切り分け不能(131 B-2 の環境センサ)。
   **単位の訂正(2026-10-19 ユーザー)**: 流量は ml/min(ml/s ではない)、チャンバー容量 54 L。50 ml_n/min は 91 mbar で実流量 ≈ 0.56 L/min → **体積交換の時定数 ≈ 1.6 h(95 % で ≈ 5 h)**で、観測した「6 時間で平衡」は単純な体積交換で説明できる(壁の脱離を持ち出す必要なし)。100 ml/min なら 0.8 h、150 なら 0.54 h。
3. 運用上は 50 ml/min で問題なし。流量を変えたら **6 時間は較正を跨がない**。

## 追記 2(2026-10-21、run 178 = 200 ml/min、同じ手順 `gas_run_178.sh`)
- run 178: 2026-10-20 15:01 – 10-21 08:11(17.2 h、265,185 events、B)。run 177 は 27 s・0 events の空 run。HV の経過: 10-19 15:50 のインターロック解除後に全 ch OFF のまま ≈ 21 h → 10-20 13:04 に全 ch ON、TR1(ch0)は 13:32 に誤って OFF(ユーザー: 他の HV と間違えた)→ 14:57 に ON。run 中は `bdilk` 0、電圧 ±0.05 V、電流 ±0.7 %。
- 推移(30 min ビン、最初の 3 h は 10 min): 最初から 17 h 平坦、平均 2.106 M(176 の平衡 2.087 から +0.9 %)。ただし 16 % 点 +6.3 %、84 % 点 +3.4 %、ヒット ch +3(124)— 一様な利得変化ではない。
- 標準指標: 長さ 86.3 / 56.8 mm(176: 84.2)、dEdx 13,929(+3.2 %)、ok 0.999、dip RMS 6.08°。
- **α 線ごとの止まる位置**(長さ × 電荷の窓の中央値、`/tmp/lines.C`): 224Ra 25.52 → 26.97 mm(電荷 305 → 334 k)、212Bi 43.65 → 45.50(646 → 688 k)、220Rn 85.51 → 87.19(1,274 → 1,315 k)、突き抜け 104.37 → 104.32 mm(837 → 849 k)。止まる位置のずれ δ = ε ×(不感区間 315 mm + 中の長さ)から密度の減少 ε = 0.43 / 0.52 / 0.42 % — 3 本で揃う。突き抜けの電荷 +1.4 % = 電離 −0.45 % × 利得 → **利得 ≈ +1.9 %**。分布の形の変化(短い線ほど電荷が大きく増える)も、不感区間で余るエネルギーがどの線にもほぼ同じだけ足されることで説明できる。
- 解釈: **密度 −0.45 % ≈ 温度 +1.3 K**(ユーザー: 気温の変動が激しく、10-20 は日中に実験エリアを開放していた)。流量 150 → 200 の効果はこの差に埋もれて見えない(100 以上は頭打ちの結論は不変)。ガス中の水が増えたなら利得は下がるはずで逆向き(湿度は主役でない)。HV 電流は同じ電圧で +0.6–1.3 %(ch4 は不変)= 湿度による表面リークの増加と整合(霧と雨)。
- 感度: 利得 ≈ +1.5 %/K(≈ −4.5 %/mbar)、飛程 0.35 %/K。**止まる α 線の位置で密度、突き抜け飛跡の電荷で利得 × 密度が分かる** = 温度・気圧の記録が無くても利得と密度を分けられる。この方法で 175 を見直すと密度 +0.08 %(利得への寄与 −0.4 %)で、−3.5 % の大半は流量(不純物)の効果のまま。
- 次: 露点の記録で 176 → 178 の間にガス中の水が動いたか確認(ユーザー)。環境センサ(131 B-2)で run ごとに T / p を記録する価値が高い。
