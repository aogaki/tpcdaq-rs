**Status: COMPLETED**(2026-10-19 起票 Fable、同日完了。ユーザー「何か違いは見えそうですか。転送に時間がかかるので向こう(ELITPC)で解析を」)

## 入力
- run 174: 2026-10-16 11:26–12:08(42 min、11,145 events、B、ZS なし)、ガス **100 ml/min**。
- run 175: 2026-10-16 12:08 – 10-19 07:52(67.7 h、1,057,719 events、B、ZS なし、raw 130 GB)、ガス **50 ml/min**(12:08 に変更)。
- 条件は同一(B = GEM 240 × 3、502 ns × 120 fC、full、25 MHz、delay 1750、DRIFT 600 × 2、CO2 91 mbar、228Th)。

## 方法(ELITPC、`~/test/scan/gas_run_161.sh` — 1 本のシーケンサ、nohup)
1. `tools/scan/gas_trend.C`(新、テスト 13 チェック緑): raw を 1 回走査し、時間ビンごと(174 = 10 分、175 = 1 時間)に
   電荷の中央値 + 16/84 %、ヒット ch、飽和率、帯の first/last、パルス幅、電荷重心時刻、レート → `~/test/scan/gas/run017N_trend.{json,png}`。
2. `metrics_for_run.sh --pressure 91`(標準の指標 + macros の飛跡)を 174 全体と 175 全体に → `~/test/scan/metrics/run017N_metrics.json`。
3. 175 の `_uvw.root` ができたらユーザーの `chargeVsTime.C`(ana_107)で電荷 vs 時刻(1 h ビン)を描く(出力は uvw の隣 = `metrics/`)。
4. 見るもの: ①電荷中央値の時間変化(不純物による付着なら全体が下がり、レートも落ちる)②ヒット ch・飛跡長・dEdx の 174 → 175 差
   ③帯位置・パルス幅(ドリフト速度・拡散 = ガス組成の変化)④飽和率(ゲイン変化)。

### 時間推移(175、1 時間ビン、統計精度 ±0.5 %)
- 電荷中央値: 0–1 h 2.05 M → 1–6 h で 2.04 → 2.00 M にゆっくり低下 → **6–68 h は 2.00 ± 0.01 M で平坦**。昼夜の周期なし、単調ドリフトなし。16 % 点も 1.39 → 1.34 M(−3.5 %)で分布全体が一様に縮む。ユーザーの chargeVsTime.C でも最初/最後の 1/4 のスペクトルは同形。
- ヒット ch 121 → 120 → 119(±1)。帯位置 first 75 / last 98 cell、パルス幅 56 cell、電荷重心時刻 90 cell: **不変 = ドリフト速度・拡散は変わらない**。
- レート 4.42 → 4.33 Hz(−2 %)、48 h 以降 4.40 に戻る。飽和率 0.8–1.2 % で変化なし。
- HV(InfluxDB、1 h 平均 69 点): vmon 全 ch ±0.05 V、imon ±0.5 %(GEM1 ch1 8.57–8.64 µA)。周期も傾きもなし。

### 判定
1. 流量 100 → 50 ml/min で **総電荷 −3.5 %、dEdx −4 %**(ゲインまたは収集効率の低下)、数時間で新しい平衡に落ち着き、その後 60 h 安定。飛跡の質(ok、長さ、dip)は不変。
2. HV は無関係。ドリフト速度・拡散が不変なのでガス組成の大きな変化ではなく、不純物の平衡か密度のわずかな変化。温度・圧力の記録が無いので切り分け不能(131 B-2 の環境センサ)。
   **単位の訂正(2026-10-19 ユーザー)**: 流量は ml/min(ml/s ではない)、チャンバー容量 54 L。50 ml_n/min は 91 mbar で実流量 ≈ 0.56 L/min → **体積交換の時定数 ≈ 1.6 h(95 % で ≈ 5 h)**で、観測した「6 時間で平衡」は単純な体積交換で説明できる(壁の脱離を持ち出す必要なし)。100 ml/min なら 0.8 h、150 なら 0.54 h。
3. 運用上は 50 ml/min で問題なし。流量を変えたら **6 時間は較正を跨がない**。
