### 1.1 `analyzeUVW.C` — ヒットを「ストリップ毎 1 点」にする
- 現行: (ch, cell) で閾値超セルを全部ヒットにし z = t·mmPerCell(§0 の系統の原因)。
- 新: チャネル毎に ped 減算波形の **最大値セル t_peak** を取り、`adc[t_peak] − ped > ADC_THRESHOLD` なら 1 点だけ push:
  - z = **電荷重み付き時刻**(t_peak ± PEAK_HALF_CELLS(既定 5)の範囲で閾値超セルのみ)× mmPerCell
  - q = 同じ窓の閾値超セルの ped 減算値の和(積分電荷。dE/dx の分子になる)
  - 2 山(同一ストリップを 2 回横切る)は mini の 1 本直線前提で無視(最大ピークのみ)。
- 以降の per-view 処理(SEED_ADC 選別 → PCA 線 → BAND_MM 帯 → width/qview/nhits)はそのまま。ただし SEED_ADC はセル値でなく積分電荷にかかるので、**閾値の意味が変わる**: seed は「帯内ヒットの電荷中央値 × 0.5 以上」等の相対値にするか、値を再調整して 09-25 データで帯内ヒット数が妥当(1 view あたり ≈ 貫通で 60〜70 ストリップ)なことを確認して結果節に記録。
- **スライス化(SLICE_MM の z ビニング)は廃止**。`slView/slZ/slS/slQ` には帯内の**ストリップ点そのもの**(view, z, s, q)を入れる(ブランチ名は据え置き、意味を冒頭コメントで更新)。
  `qview/width/nhits/eventId` は契約維持(chargeVsTime.C が読む)。

### 1.2 `makeTracks.C` — 3 view の 2D 直線から 3D 直線
z スライス重心の三角測量(現行手順 1)は水平飛跡で退化するため廃止。mini = 1 直線の前提で:
1. view v ごとに帯内点 (s, z, q) の電荷重み付き平均 (ms_v, mz_v) と 2×2 PCA 主軸 (u_v, w_v)(u = s 成分、w = z 成分、正規化)。点が 3 未満の view は捨て、有効 view が 2 未満なら ok = 0。
2. **方向** d = (dx, dy, dz): 3D 直線を view v に射影した向きは (pitch_v·(dx,dy), dz) で、これが (u_v, w_v) に平行 →
   制約 `w_v·(pitch_v·(dx,dy)) − u_v·dz = 0`(view 毎 1 本、電荷 qview_v で重み)。3×3 の正規方程式 M = Σ q_v a_v a_vᵀ(a_v = (w_v·p_v0, w_v·p_v1, −u_v))の**最小固有値の固有ベクトル**が d(TMatrixDSymEigen、列 2)。水平飛跡(dz = 0)でも退化しない。
3. **位置** p0: (x0, y0) は現行と同じ最小二乗 `pitch_v·(x0,y0) = ms_v`(有効 view で正規方程式)、z0 = Σ q_v mz_v / Σ q_v。
4. **端点**: 各 view の各点を、その view に射影した直線 (s(t), z(t)) = (ms_v + t·pitch_v·d_xy, z0 + t·dz) に射影して t を求め(射影方向 (pitch_v·d_xy, dz) で正規化)、**全 view をプールした** 2 %–98 % 電荷分位で lo/hi。start/end・length・charge・dEdx・dirX/Y/Z の出力契約は据え置き(手順 4 の電荷ヘビー側 = end もそのまま)。
- `MIN_SLICES` は「有効 view 数 ≥ 2 かつ総点数 ≥ 6」等に置換。

### 不合格の原因(2 つ。診断のみ、実装には入れていない)
- **(a) オフトラックのハロー(主因)**: 事象ごとにほぼ全ストリップ(先頭 1000 事象で平均 236/256 本)が飛跡時刻付近に小パルス(ピーク 35–~200 ADC)を持つ。
  FPN(ch 11/22/45/56)には出ない(ピーク 11–15 ADC = ノイズ)ので AGET コモンモードではなく、FPN 減算では消えない。
  ストリップ毎 1 点化でこれらが z ≈ 飛跡時刻の点になり、**浅い飛跡では V/W 上で飛跡と同一直線 → ±10 mm 帯を通過**(≈ 23 点/view)→ 全 view プールの 2–98 % 分位が外へ伸び L_xy 膨張、θ を 0 に引く(スパイク)。
  旧チェーンでは同じハローがスライス重心で薄められていた。
- **(b) \|θ\| → 0 で面内方向が退化(§1.2 手順 2 の方式固有)**: dz → 0 で全 view の主軸が (u, w) → (1, 0)、a_v → (0, 0, −1) で M は rank 1、d_xy が決まらない

  「水平飛跡でも退化しない」は θ(dz)については正しいが φ については \|θ\| ≲ 2–3° で成り立たない。

**合成テスト(§3 の要求: θ = 0, φ = 10° を含む、z ノイズ 0.3 mm)**:
- 固定ケース(z ノイズ 0.3): (θ, φ) = (0, 10) → (0.01, **8.64**)、(5, 10) → (5.13, **7.26**)、(−20, −12) → (−20.37, **−9.57**)、(60, 40) → (59.99, 39.76)、(17, 0) → (16.98, 0.00)。θ = 0 の退化は解消(round 1 は φ = 0, L = 114)。
- ランダム 2000 本(θ ∈ ±30°、φ ∈ ±15°、L = 106): φ 誤差 RMS **2.32°(\|θ\| 0–3°)**、2.2–3.0°(他の全 θ ビン)→ **「≲ 1°」は不合格**。
  φ の符号付き誤差(+ = 0 から離れる向き): \|φ\| 0–3: −0.86 / 3–6: **−2.89** / 6–9: −2.57 / 9–12: −1.32 / 12–15: −0.52 → **0 に向かう系統**(D が大きく出る原因)。θ 誤差は RMS ≤ 0.27°。
- **原因**: 分位で取った広がり Δs_v には、真の L·|pitch_v·d_xy| に比例しない**絶対オフセット**が乗る(N 本のストリップの幅 = (N−1) ピッチ、2 % 分位の床関数で 1–2 本落ちる、拡散幅)。

## 4. 第 3 ラウンド発注(2026-09-28 Fable 裁定 — 第 2 ラウンドの「分位広がりのオフセット」問題)

分位で取った広がり Δs_v は「長さから定数を引いた量」なのでオフセットが消えない(二次形式でも一次形式でも残る)。
**広がりでなく電荷重み付き二次モーメント(分散)を使う**と、view 毎に足される平滑化(ストリップピッチ、拡散、端の落ち)は
`p_vᵀ(cI)p_v = c` = 2D 共分散への **c·I の加算**に等しく、**固有ベクトル(= 方向)を動かさない**。全電荷・全ストリップを使うので分位の床関数もない。

手順 2 を次に差し替え(§3 の Δs 方式は削除):
1. view v ごとに、帯内ストリップ点の **電荷重み付き平均 ms_v と分散 σ_v² = Σq(s − ms_v)²/Σq**。
2. 2D 共分散を 3 射影から復元: `Σxx = σ_U²`、`Σxy = (σ_V² − σ_W²)/√3`、`Σyy = (σ_V² + σ_W² − 0.5·σ_U²)/1.5`
   (p_U = (−1,0)、p_V = (0.5, 0.866)、p_W = (0.5, −0.866) から σ_v² = p_vᵀ Σ p_v を解いたもの)。
3. `[[Σxx, Σxy],[Σxy, Σyy]]` の**最大固有値の固有ベクトル**を d_xy(2×2 なので閉形式でよい: tan 2φ = 2Σxy/(Σxx − Σyy)、φ = 0.5·atan2(2Σxy, Σxx − Σyy))。
   ガード: λ_max − λ_min < 1 mm²(z 向き飛跡 = xy に広がりなし)なら ok = 0。クリップは不要(負の Σyy は雑音として固有ベクトルに任せる)。
4. 以降(ℓ = (s − ms_v)/(pitch_v·d_xy)、|pitch_v·d_xy| ≥ 0.3 の view、z(ℓ) 回帰、ℓ 分位の端点、契約)は第 2 ラウンドのまま。

期待値(合成、z ノイズ 0.3 mm): φ 誤差 RMS ≲ 0.5° で θ に依らず、**tanφ のスケール系統なし**(θ=0, φ=10° → 10.0 ± 0.5)、φ = 0 のスパイクなし。
実データ: D が全 θ / |θ| ≥ 3 / 5 / 10° で **統計誤差内で一定**、346 ± 7 と整合。結果節に「第 3 ラウンド」として v1 / r1 / r2 / r3 を並記。README の方式説明も合わせる。
