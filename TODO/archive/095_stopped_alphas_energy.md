# 095 — stoppedAlphas.C: ケージ内で止まった α の残エネルギー(飛程法、NIST ASTAR)+ 電荷との線形性

**Status: COMPLETED**(2026-09-28 起票・実装 Fable。ユーザー「エネルギーを推定してヒストグラムに。中で止まったものだけでいい」)

## 0. 方法
- `macros/stoppedAlphas.C`(新規): tracks ツリーを +x 向きに揃え、|φ| ≤ 15°、左壁から入る(xStart < −43)、内部で終わる(xEnd < 43、y 壁・z 窓から 10 mm 以上)、長さ ≥ 15 mm。
  残飛程 = 壁面交点(直線上の x = −53)→ 終点の 3D 距離。**NIST ASTAR の α in CO₂ CSDA 飛程**(0.5–10 MeV、`~/test/gas-pressure-test/reference/astar/alpha_in_CO2.txt` から転記、log-log 補間)を run のガス密度(理想気体、100 mbar / 293.15 K → 0.1806 mg/cm³)でスケールして E に変換。
- 出力: E ヒスト、x_end(1.5 mm ビン = ストリップピッチ)、電荷(3 view 和)vs E + プロファイル。Bragg ピーク判定は未実装(隙間や死領域で消えた飛跡も「停止」に数える)。
- 付随: `sourceTracks.C` の SRC_X を −410 → **−470**(下記の理由)。

## 結果(2026-09-28、Mac、ROOT 6.40.04、09-25 run、`root -l -b -q 'stoppedAlphas.C("data/CoBo_2026-09-25T08-56-08.494_tracks.root")'`)
```
CO2 density 0.1806 mg/cm3 (100 mbar, 293.1 K); ASTAR CSDA ranges [mm]: 212Bi 6.05 -> 325, 220Rn 6.29 -> 345, 216Po 6.78 -> 388, 212Po 8.78 -> 586
stopped inside (source-like, |phi| <= 15 deg): 15140 tracks
charge = 1.16e+05 + 4.42e+05 * E [ADC, 3 views]   (profile fit 0.5–2.5 MeV)
```
- **残エネルギー分布は 0.5〜2.6 MeV でほぼ平坦**(2.6 MeV ≈ 残飛程 96 mm = ケージ幅で切れる)。線ではない = 停止しているのは線源からの単色 α ではなく、**ケージ外のガスで崩壊した ²²⁰Rn 系列**(始点が一様 → 残飛程が一様)。線源の ²¹²Po は残飛程 169 mm で貫通。
- **x_end に ²¹⁶Po の帯なし**(線源 −410 なら x ≈ −22 に鋭い帯が出るはず)→ 壁まで ≥ 380 mm → **線源はユーザー申告の −470 が正しく、xy 回帰の −410 は Rn 雲 + ポート開口による偏り**(093 追記 3 訂正)。
- **電荷 vs E は線形**: 4.42 × 10⁵ ADC/MeV(3 view 和)、切片 1.2 × 10⁵(端点の 2 % 分位で残飛程が 1〜2 mm 短く出る分 + ハロー分の候補)、帯の幅 ≈ ±10 %。= 飛程法と電荷法が整合。電荷法の較正点として使える。
