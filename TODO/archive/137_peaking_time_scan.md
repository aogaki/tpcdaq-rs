## 読み
> **訂正(2026-10-14 夜、139 で試験済み)**: 下の「電荷は peaking とともに 1 → 2.3 → 5.2 倍 … 現用 232 ns は信号の一部しか積分していない」は誤り。ここの電荷は**サンプルの和**で、同じ入力電荷でも整形パルスの面積(核の和 9.7 / 20.7 / 40.3、archive/138)に比例して増える。138 の核で逆畳み込むと 232 : 502 : 1014 = 1 : 1.05 : 1.21(= パルサーのピーク利得比)に揃う → 総電荷はどの peaking でも取り切れている。peaking で本当に変わるのはピーク高さ(S/N、閾値通過、飽和)と時間幅。
- **電荷は peaking とともに 1 → 2.3 → 5.2 倍**(232 → 502 → 1014)。検出器の電荷到着が µs 幅なので、短い整形は振幅を取り切れない(ballistic deficit)。**現用 232 ns は信号の一部しか積分していない**。70 ns は弱いストリップが閾値(35 ADC / STRIP_Q_MIN 2000)を割り、ok 66 %、長さ 45 mm = 飛跡として大損(目視の「弁別が良い」は明るいストリップだけが残った姿)。
- 長い整形ほど弱いストリップを拾い(ヒット ch 121 → 147)、飛跡の端が伸び(85 → 105 mm)、dEdx の相対幅が縮む(0.52 → 0.43)。
- 代償: **飽和**(1014 ns で 1/3 のイベントに 4095 の ch、502 ns で 4.8 %)と **時間幅**(パルス幅 1.6 → 2.5 → 4.2 µs = z 分解能と窓の占有)。
- 帯の位置は peaking 分だけ遅れる(Δfirst = +7 / +20 cell = 270 / 780 ns = peaking の差)→ delay のルールの L は `0.16 µs + peaking`。
- 次 = gain スキャンを 502 ns で(120 fC / 240 fC / 1 pC)+ 1014 ns × 1 pC(run 87〜、13:30 開始)。
