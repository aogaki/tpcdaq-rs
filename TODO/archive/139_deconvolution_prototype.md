# 139 — 整形デコンボリューションの試作(138 の核で α 波形を戻す)

**Status: COMPLETED**(2026-10-14 起票 Fable。ユーザー「いわゆるデコンボリューションが可能かも考えたい」。138 で核が取れ、揺れは電子回路由来でないと分かった後の発注)

## 0. 目的と判断基準
138 の核(peaking 70 / 232 / 502 / 1014 ns、`~/test/scan/kernel2/run010{3,5,7,9}_kernel.json` の `all.mean_norm`、t = −40…+300 cell @ 40 ns)で α 波形(137 / 140 の run 84–88、25 MHz)を**正則化付きで逆畳み込み**し、次を数字で出す。
1. **電荷の回復**: 232 ns の run 84 をデコンボリューションした電荷が、502 ns(run 85/87)・1014 ns(run 86)の電荷と**同じ比(1 : 2.3 : 5.2 → 1 : 1 : 1)に揃うか**(= ballistic deficit を外せるか)。揃えば短い整形 + デコンボリューションで「飽和しない & 電荷が取れる」運用が成立する。
2. **時間幅**: デコンボリューション後のパルス幅(FWHM)と、ストリップ間のピーク時刻のばらつき(z 分解能の代理)。
3. **ノイズ増幅**: ped 領域(ヒット無し ch)の RMS がデコンボリューション前後で何倍か。正則化パラメータ 3 点で表にする。
4. 揺れ(137)が**残る**ことの確認(残るのが正しい — 138 の結論)。

## 1. 実装(`tools/scan/deconv.C` + `test_deconv.C`、ROOT マクロ、C++17。`run_metrics.C` を include して前処理を共有)
- 核: JSON の `mean_norm` を読み、ピークを t = 0 に置いた長さ 341 の離散核 h[k]。ピーク前 −40 は核に含める(整形の立ち上がり)。核の尾の一定オフセット(≈ +1 %)は +50…+300 の平均を引いて 0 にする。
- 方法: **周波数領域の Wiener 型**(KISS、FFT は ROOT の `TVirtualFFT`): `X̂(f) = Y(f) · H*(f) / (|H(f)|² + λ)`、λ = ノイズ/信号比の 3 点(例 1e-3 / 1e-2 / 1e-1 × max|H|²)。波形は FPN + ped 減算後の 512 cell、端は 0 詰めで 1024 点。
- 出力(JSON): run ごと・λ ごとに、ヒット ch の電荷(和)の中央値、FWHM 中央値、ped 領域の RMS(前 / 後)、ピーク時刻の ch 間ばらつき。PNG: 1 イベントの 1 ch の前後重ね + 電荷比の表。
- 入口: `int deconv(const char* raw, const char* kernelJson, const char* outJson, double lambda, const char* outPng = nullptr, int maxEvents = 0)`。

## 2. テスト
- 合成: 既知の「真の電流」(矩形 + 指数尾)を核で畳み込んでノイズを足し、λ を小さくすると真の電流に戻ること(電荷 1 % 以内、λ = 0 で厳密に戻る)、λ を大きくするとノイズ RMS が下がり幅が広がること(単調)を検査。
- 核の読み込み(JSON のキー、ピーク位置 = index 40)、オフセット除去、無いファイルで 1。
- 赤 → 緑の実測、既存 3 本(`test_run_metrics` 88、`test_pulser_kernel` 237、`test_drift_end` 88)の回帰。

### 答え
1. **電荷の回復**: 逆畳み込み後の電荷比は 232 : 502 : 1014 = **1 : 1.05 : 1.21**(前は 1 : 2.24 : 5.0)。これはパルサー(同一入力電荷)のピーク利得比 1 : 1.05 : 1.17(138)と一致する。→ **サンプル和の電荷は、どの peaking でも入力電荷を取り切っている**(線形系の面積 = 入力電荷 × 核の和。核の和 9.7 / 20.7 / 40.3 × 利得差 = 1 : 2.24 : 4.8 ≈ 実測)。**137 の「現用 232 ns は信号の一部しか積分していない」は誤り**(試験済みなので archive/137 に訂正注記)。peaking で変わるのは**ピーク高さ**(飽和率 0.3 → 4.8 → 34 %、弱いストリップの閾値通過 121 → 128 → 147 ch)と時間幅であって、総電荷ではない。ballistic deficit はピークにだけ効く。
2. **時間幅**: 整形を外すと FWHM は 13.7 / 14.6 / 18.7 cell(0.55 / 0.58 / 0.75 µs、λ 1e-3)= **検出器側の固有幅(電荷到着の広がり)に収束**。1014 ns では 43 → 19 cell と半分以下。ch 間のピーク時刻のばらつき(≈ 7 cell)は飛跡の傾きで決まり、逆畳み込みでは変わらない。
3. **ノイズ増幅**: S/N 代理は λ 1e-3 で ×0.4–0.5、1e-1 で ×0.86(幅の回復は弱まる)。運用値は **1e-2**(電荷 −1 %、幅は 1e-3 に近い、S/N ×0.6–0.7)。
4. 揺れは本票では未測定(138 の結論 = 電子回路核では外れない、で足りる)。

### 裁定(Fable)
- **「短整形 + デコンボリューション」運用は採らない**: 電荷はどの peaking でも和で取れているので、逆畳み込みの利得は時間構造だけ。E(一晩)は 140 のとおり **502 ns × 240 fC**(弱いストリップの検出効率と飽和 0.7 % の両立)。
- 逆畳み込みは **オフラインの選択肢**として残す(1014 ns のデータで z 構造を見るとき、λ 1e-2)。130(複数飛跡)で重なったパルスの分離に使えるかは、そのときに判断。
- 道具: `tools/scan/deconv.C`(`4e25dba`)。Mac は FFTW 無し(O(N²) DFT、遅い)、ELITPC は FFTW あり(30 s/run)。
