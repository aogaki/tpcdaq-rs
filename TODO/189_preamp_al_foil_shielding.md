- **訂正(2026-10-25 ユーザー)**: 対象は AsAd ではなく、**HV のフィルタボックスから繋がるトリガ用のプリアンプ**(GEM 信号 → CFD → zCoBo の外部トリガ、131 B-3)。

### 2026-10-25 昼(続き): 外の EM 雑音か(ユーザー「朝来た段階で CFD のトリガ LED が点きっぱなし」「O ビームを 200 ms 周期のパルスにする作業中で EM ノイズが飛んでいるのかも」)
- 道具: scratchpad `noise189/dt_pairs.C`(事象時刻の全ペアの差、10 ms 刻みで 1.05 s まで)と、連続する事象の間隔の Poisson との比較。
- **200 ms の周期は見えない**: run 205(80.2 Hz、35.6 s)・207(0.66 Hz、567 s)とも 200 / 400 / … / 1000 ms の山なし(比 0.7–1.2)= トリガは 5 Hz の外部のパルスに同期していない(この時点では)。
- **run 205 = 雑音で起動しっぱなし**: 80 Hz、連続する間隔 < 5 ms が 0(Poisson なら 943)= 不感時間で頭打ちのトリガ(LED 点きっぱなしと整合)。
- **run 207 = 束になって来る**: 0.66 Hz なのに、連続する間隔 < 20 ms が 42(Poisson 4.9 = 8.6 倍)= 散発的な雑音の塊がまとめてトリガを起こす(EM の突発と整合、周期性なし)。
- 結論(暫定): 今日は外から(隣のビームの作業)散発的な雑音が来ている可能性が高い。フォイルの前後の比較は、この外乱が収まってから続けて(前後を間を空けずに)取る。HV ケーブルの差し直しの確認も残す。

### 2026-10-30: 11/9 の中性子実験(隣、TPC は線源から ≈ 3 m)での意味
- 物理のトリガは ≲ 1 Hz の見込み(気体 TPC の中性子の反応確率 ≈ 3 × 10⁻⁴ / 10 cm、ガンマの電子はほぼトリガしない — 173)。**高レートの危険は雑音トリガ**: run 205 は雑音で 80 Hz に張り付いた(run 197 の 76 Hz と同じ帯域 → 184–188 が要る理由の一つ)。
- 全読み出し ≈ 0.41 MB / 事象(graw 0.28 + raw.root 0.13)→ 80 Hz の雑音が続くと ≈ 33 MB/s ≈ 2.8 TB / 日 → 空き 21 TB は ≈ 1 週間。気づかずに一晩続くと ≈ 1.4 TB の雑音。
