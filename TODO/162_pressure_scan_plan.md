# 162 — 圧力スキャン(≤ 300 mbar、線源を端置き)の計画 + `alpha_lines.C`

**Status: READY**(2026-10-19 起票 Fable。ユーザー: 圧力は 300 mbar まで、線源はケージ内の端(中心から ≤ 70 mm)、**z はまず中間(100 mm)で圧力と x 位置を変える**。目的 = エネルギー分解能の圧力依存を明確にする。できれば 8.78 MeV 以外の 228Th 系列 α を一度に収納)

## 1. 前提(161 の付随結果と飛程表)
- 228Th 系列: 228Th 5.42 / 224Ra 5.69 / 212Bi 6.05–6.09 / 220Rn 6.29 / 216Po 6.78 / 212Po 8.78 MeV。
- 飛程(SRIM、TPCReco `resources/range_corr_thr_1keV_alpha_10MeV_CO2_250mbar.dat` を 1/p で伸縮)[mm]:

  |---|---|---|---|---|---|---|

  | 250 | 114 | 122 | 136 | 143 | 160 | 241 |
  | 280 | 102 | 110 | 121 | 127 | 143 | 215 |
  | 300 | 95 | 102 | 113 | 119 | 133 | 200 |
- 活性領域(実ジオメトリ): x 幅 108 mm(U 72 本 × 1.5 mm)、y 幅 ≈ 100 mm、ドリフト 200 mm。
- **収納率(飛跡全体が活性領域内、等方 4π に対する %、z = 100 mm)** — MC(箱 108 × 100 × 200 mm):
  | x0 | p | Th | Ra | Bi | Rn | Po216 | Po212 |

  内向きの箔なら実質 2 倍。**x0 = 70(端)が高い線ほど有利**、x0 を内側にすると低い線だけが残る(位置依存の検証に使える)。212Po は常に突き抜け = dE/dx の基準線。
- 測定レンジ: **220–300 mbar**。130 mbar 以下では収まる飛跡が無い。
- 電子回路: 12.5 MHz(6.25 は無い)。窓 41 µs。DRIFT 2 kV 上限で v ≈ 0.24–0.33 cm/µs(窓 99–135 mm)。z 成分が窓を超える飛跡は last hit の窓末尾で除く。
- GEM 出発点(Warsaw ELITPC の運用点 130: 245–255 / 190: 260 / 250: 270 V → 外挿 280: ≈ 280、300: ≈ 290 V)。ただし飛跡が短くなりストリップあたりの電荷が最大 4 倍になるので、**飽和 < 2 %(E 規則)で下げる方向**。gain 240 fC / 1 pC も候補。TR 350 は据え置き(ヒット ch が落ちたら +20–40 V)。DRIFT: E/p 0.66 を保てるのは 150 mbar まで、以降 2 kV 固定。
- HV・ガス圧・線源の操作はユーザー。値の指示はしない(出発点の提示まで)。

## 2. 測定の順番(各点 = GEM 小スキャン(±10 V の 2 点)→ E 規則 → 1,500 events の標準 run → 長い run 1 本)
1. 300 mbar、x0 = 70、z = 100: 5 線の収納と分解能の基準点。delay は帯位置から取り直し(12.5 MHz の規則 3800 を出発点)。
2. 300 mbar で x0 = 50、40: 位置依存(低い線だけが残る)。
3. x0 = 70 で 280 → 250 → 220 mbar: 線が 1 本ずつ突き抜けに変わる様子と、残った線の分解能の圧力依存。
4. 余裕があれば z を読み出し面寄りに(収納率 ↑、低圧側に伸ばせる)。

## 3. 指標(`alpha_lines.C`、発注 = Sonnet、テスト付き)
入力 = `_tracks.root`(makeTracks: ok, length, charge, dirX/Y/Z, start/end)+ `_uvw.root`(analyzeUVW: ヒット `slView/slS/slZ/slQ` — 端点の定義 (b) に要る)+ 指標 JSON。出力 = JSON + PNG。
- **線の切り出し**: 長さ × 電荷の 2D で塊を見つける(k 個の初期値 = 飛程表 × 圧力、窓 ±15 % → 中央値で反復)。塊ごとに本数、長さ中央値 / FWHM、電荷中央値 / FWHM、**電荷 FWHM/平均 = エネルギー分解能**、長さ FWHM = 飛程ストラグリング。
- **収納判定**: 端点が境界から ≥ 5 mm 内側(境界 = rangeXY と窓の z 範囲)。突き抜け(105 mm の塊)は別に数える。
- **Bragg**: 末端 10 mm / 先頭 10 mm の電荷比、頭尻が決まる割合。
- **端点(= 飛程)の定義を 2 通りで比べる**(2026-10-20 追加。xy の重心精度は飛跡全体では 0.03–0.05 mm 級まで平均されるので、長さの FWHM = エネルギー分解能に効くのは重心ではなく端点の切り方の系統):
  - (a) **電荷分位**(現行): makeTracks の 2–98 % 電荷分位の点(`start`/`end`、`length`)をそのまま使う。
  - (b) **Bragg 末端の閾値**: ヒットを飛跡の直線へ投影して l を求め(hit_residuals.C と同じ式)、l の 1 mm ビンで電荷の縦断面を作る。頭尻(上の Bragg 比)で止まる側を決め、止まる側の端点 = Bragg ピークの後ろで縦断面が f × ピークを最後に下回る l(ビン間は線形補間)。f = 0.5 を既定に 0.3 / 0.7 も出す。始まり側の端点は (a) の値を使う(始まり側は dE/dx が低く、ピーク比の閾値では大きく削れるため)。頭尻が決まらない飛跡は (b) から外して数える。
  - 出力: 線ごとに (a) と (b, f = 0.3 / 0.5 / 0.7) の長さの中央値と FWHM、(a) − (b) の中央値(定義の系統差)。長さ FWHM が小さい方を分解能の定義に採る(採否は結果を見て主対話が決める — implementer は決めない)。
  - 線源がケージ内の既知位置にあるときの参考として、(c) 線源位置から (b) の止まる側の端点までの距離も出す(線源座標は引数、無ければ省略)。
- 従来指標(帯位置、パルス幅、σ_z、σ_2D、飽和率)は run_metrics / hit_residuals / uvw_closure をそのまま。
- 受け入れ: 合成 tracks(2 線 + 突き抜け)で塊の分離と FWHM が入力どおり ±5 %。端点 (b): 合成ヒット(既知の Bragg 形の縦断面 + 雑音、真の止まり点を与える)で f = 0.5 の端点が真値 ±0.3 mm、頭尻を逆にしても同じ端点、頭尻が決まらない形(平坦な縦断面)は (b) から除外されて数えられる。(a) は makeTracks の `length` と一致(再計算しない)。実データ run 175 で 220Rn 85 mm / 1.25 M、212Bi 45 mm / 0.65 M、224Ra 25 mm / 0.30 M、突き抜け 105 mm が出る。
