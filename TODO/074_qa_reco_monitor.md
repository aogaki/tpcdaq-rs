1. **フィクスチャオラクル**: minitpc simplefit(Python、`~/Workspace/Higs/minitpc-analysis`
   — **読み取りのみ、Higs 側は変更しない**)から入力ヒット + 期待トラックパラメータの
   フィクスチャを生成。生成スクリプトと出力はこちら側リポに置く(合成入力のみ。実 .graw

2. **純関数コア(Rust)**: simplefit 移植(ビュー毎 PCA → ±3σ バンド再選択 →
   z スライス三角測量 → 3D PCA)。IO 非依存。①のフィクスチャ一致テスト
   (許容誤差つき、**Python が正**)。
3. **monitor 統合**: built_event PUB(§5.3、20 Hz)の購読側に接続。1 トラック仮説 = 設定値。
   仮説違反は reject + カウント + status 表示。頭尻なし。mm は本モジュール内限定
   (TPCReco 規約、§4.4 v1.25)。
4. **WS**: QA ヒスト id 20 番台(0x10/0x11 流用、「sampled」明示)。UI パネル(Angular)は
   分割候補。
5. **受け入れ**: reco on/off で §12-8(保存スループット)と WS 配信(ドロップ・遅延)が不変。
