- **判定: 100 が正しい。止まっている 3 本は ²¹²Bi / ²²⁰Rn / ²¹⁶Po**。根拠:
  1. 2 本(²²⁰Rn / ²¹⁶Po)で密度と線源距離を解くと、使っていない ²¹²Bi が +0.4 / −0.7 mm で乗る。
  2. 中間 : 深い = 244,961 : 241,211 = **1.02**(175)。161 の読み(²¹²Bi : ²²⁰Rn)なら ≈ 0.36。ユーザーの観察(ほぼ同数)と一致。
  3. 線源で生まれたと仮定した E(公称密度・−370)が 5.95 / 6.15 / 6.65 → 100 の読みなら 3 本とも −0.11〜−0.14 MeV でそろう、161 の読み(5.69 / 6.06 / 6.29)なら +0.27 / +0.09 / +0.36 でばらばら。
- ²¹²Bi / ²²⁰Rn = 0.297(175)→ 0.336(178)。178 は密度 −0.7 % で線が 2 mm 深い = 閾値で切れる分が減る、という 100 の説明どおりに期待値 0.359 へ近づく。
- FWHM 1.5–1.6 % は 100(10-02、2.2–2.8 %)より良い(25 MHz・運用点 B)。差 +0.02 MeV は F 端点の系統(100 と同じ向き)。2 本はフィットに使っているので、独立な検証は ²¹²Bi の位置と、3 本の FWHM。

### 追記: 線源位置と密度の縮退(ユーザー「-350 mm あたりでいい感じの結果になりますね」)

- 不感区間の損失は 密度 × 距離 でほぼ決まるので、E だけでは (srcX, ρ) が縮退する。破るのは**線の間隔**(²²⁰Rn → ²¹⁶Po ≈ 46 mm、線源位置に依らず密度だけで決まる。100 mbar なら ≈ 43 mm)。誤った密度は「E に比例して傾くずれ」になる。
- (−350, 100) から始めても 3 本フィットは 93.8 mbar 相当・x_src = −373 に戻る。実測の線源位置(ユーザー申告 −370)と合うのは −373〜−376。
- −350 が良く見えるのは密度を 100 mbar 相当で計算した場合(`stoppedAlphas.C` の圧力の既定値は 100)。**ユーザー確認: 圧力を 100 のまま回していた**(2026-10-21)→ 縮退で説明済み。91 で回し直せば −373〜−376 の見込み。
  161 のずれも 100 mbar 相当の表が原因かもしれない(未確認)。再発防止案: 圧力引数の既定値を外して省略時はエラー(ユーザー判断待ち)。
- 残る ×1.02 は温度 14 °C か圧力 93 mbar(切り分けには圧力計の実値か温度 = 165)。
