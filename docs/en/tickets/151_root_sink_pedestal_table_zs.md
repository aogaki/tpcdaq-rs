## 0. Problem
The pedestal in `tools/root_sink/pevent_fill.hpp:304-358` (mean of cells 5..25 − cell mean of FPN, a faithful port of TPCReco `PedestalCalculatorGRAW`) gives offset ≈ 0 / bias and an FPN term of 0 on zCoBo ZS data (samples below threshold **do not exist**; FPN channels are suppressed too), so the chargeMap of PEventTPC stays at raw ADC (= it breaks the same way in TPCReco). archive/149 run 133.

## 1. Specification
1. **Configuration**: `ped_table: Option<PathBuf>` in `SystemConfig` of `src/config.rs` (`[system] ped_table = "/path/pedestal_502ns.json"`). Like `geometry`, check existence at parse time (error if missing). Add it with a note to `config/daq_example.toml`. `tools/deploy/daq_up.sh` reads it with `toml_get` and passes `--pedestal-table FILE` to root_sink (make the key name unique within the file).
2. **Table**: the JSON of `calib pedestal` (`src/calib/pedestal.rs`: `{meta, channels:[{asad, aget, ch, mean, rms, runs, is_fpn}]}`). root_sink has no JSON parser, so in `tools/root_sink/ped_table.hpp` (new) write the same flat-object scan as `loadPedTable` at `tools/scan/run_metrics.C:211-249`, and put it into `double mean[nAsad][4][68]` (NaN for missing channels). CLI `--pedestal-table FILE` (cannot open / no `channels` = startup error, in the style of SPEC §3.2). At startup log the path, the generation date/time in `meta`, and the number of channels.
3. **Predicate for ZS-like frames** (`Filler::frame_is_zero_suppressed()`, from the counts in `grid_`): in that (cobo, asad) frame, among channels that "have at least one sample", if a **majority** have "number of samples inside the ped window [min_pedestal_cell, max_pedestal_cell] (default 5..25 = 21 cells) < 21", the frame is ZS-like. Full / partial (non-ZS) have all cells for the channels read, so false; ZS has almost no pre-trigger samples, so true.
4. **Table mode** (ZS-like && table present): correction = the table's mean(asad, aget, raw_ch), **no FPN term**, signal window unchanged, `value = adc − mean` only for the samples that exist, passed to `AddValByStrip` (missing samples stay absent from the chargeMap), `pedestalSubtracted = true`. Channels not in the table are skipped and counted in `pevent_table_missing_channels` (WARN once).
5. **No table** (ZS-like && no table): keep the conventional algorithm + count in `pevent_zs_frames_no_table`, WARN once per run. **Do not stop storage** (graw is the safety net).
6. **Non-ZS frames**: even if a table is configured, **keep the conventional algorithm** (bit-identical) -> the oracle of §12-3 (agreement with grawToEventTPC) is unchanged.
7. Counters `pevent_zs_frames_table / pevent_zs_frames_no_table / pevent_table_missing_channels` go into the final JSON (the path that goes into run_stop). The close line is not changed.
