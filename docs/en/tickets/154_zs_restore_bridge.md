## 0. Rationale
The macros (`macros/analyzeUVW.C:192-198`, read only) use ped = mean of cells 1..20, threshold 35, no FPN. With ZS raw (missing cells = 0), ped ≈ 0 and it breaks (archive/149: length 126 mm, σ_z 0.73). If the suppressed cells are filled with round(mean) of the table, ped = the table's mean (all 20 cells being suppressed essentially always holds, P ≈ 3e-7), and the filled cells are ignored since `val = 0 ≤ 35` -> the same behaviour as non-ZS (the only differences are the ZS-specific loss in (ped+35, ped+max(5σ,20)) and a rounding of ≤ 0.5 ADC).

## 1. Specification
- `int zs_restore(const char* rawIn, const char* pedJson, const char* rawOut, int maxEvents = 0)`: write out the contract of the raw tree as is (`eventId/i`, `eventTime/l`, `adc[N][68][512]/S`, N from the length of the leaf), with the rule **cell == 0 and the ch is in the table -> round(mean)** (FPN channels too). Channels not in the table are unchanged + counted (WARN once). Print the events / number of filled cells. `rawOut == rawIn` is refused (1).
- `metrics_for_run.sh --zs-fill` (`--ped FILE` required): restore into `OUT_DIR/zsfilled/runNNNN_raw.root` (**same name required** — the macros build the output name by replacing `_raw.root -> _uvw.root`; with a different name analyzeUVW would RECREATE its input) -> run macros + `run_metrics --ped` there -> the metrics JSON goes in OUT_DIR (`raw_file` = the restored path).
- A section in the README. In the ticket, put the **minimal patch proposal for analyzeUVW.C** as wording (optional 3rd argument `pedJson`, replace the cells 1..20 loop with `ped = table[a][c]`, about 15 lines, makeTracks unmodified) (not applied).

## 2. Tests (`tools/scan/test_zs_restore.C`)
(a) ZS synthetic -> each cell is the original value or round(mean), cells of the pulse are identical. (b) Non-ZS input -> identical tree. (c) **Sanity**: `runmetrics::computeRunMetrics(restored, no table)` == `computeRunMetrics(ZS raw, table)` (charge_median ±1 %, hit_channels equal — the hit definition of run_metrics is that of analyzeUVW). (d) Channel not in the table -> unchanged + counted. (e) Same-name refusal.
