## 0. Principle
The pitch vectors of U/V/W (macros: U (−1, 0), V (0.5, +0.866), W (0.5, −0.866)) sum to zero, so the strip coordinates of the same point (x, y) satisfy **s_U + s_V + s_W = constant (c)**. The charge centroids of the three planes in the same time slice (same z) should point to the same (x, y), so the spread of the closure residual r = s_U + s_V + s_W − c gives the **2D centroid accuracy, independent of any track model** (σ_r² ≈ 3 σ_s², σ_s = centroid accuracy of one plane). This is the 2D version of 146 (z residual).

## 1. Inputs
- Raw tree (`metrics/run%04d_raw.root`, same preprocessing as run_metrics.C: FPN common-mode subtraction, ped cells 1..20, threshold 35 ADC, cell range [2, 508)).
- Strip mapping: `channel_map.csv` (ELITPC `~/test/ana/ana_107/`, same as the macros). **Read and replicate** how `analyzeUVW.C` reads it (meaning of the columns, s = pos [mm], view 0/1/2) — do not modify the macros.
- Track selection: only events with `ok == 1` in `metrics/run%04d_tracks.root` (same as 146).

## 2. What to build: `tools/scan/uvw_closure.C` + `test_uvw_closure.C`
- Entry point `int uvw_closure(const char* raw, const char* channelMap, const char* tracksRoot, const char* outJson, const char* outPng = nullptr, int maxEvents = 0)`.
- For each event (ok==1) and each cell t (slice width 1 cell, with a `kSliceCells` constant so that slices can be merged into 2–4 cells if needed): in each view, the charge centroid s_v(t) of the strips over threshold (weight = ADC − ped − FPN of that cell). Only slices with ≥ 1 strip in all three views (and with the hits of each view forming one contiguous cluster = to avoid multiple tracks; slices with two or more clusters are discarded and counted) are accepted.
- c is the median of r over the whole run (geometric offset). Output: robust σ of r (1.4826 × MAD), RMS, median (= c), number of accepted slices, number of discarded slices (insufficient views / multiple clusters), **robust σ per quartile of slice charge**, and the median number of over-threshold strips per view (the width used for the centroid). PNG: histogram of r + r vs slice charge.
- Units are mm. σ_s = σ_r / √3 is also written to the JSON (`sigma_per_view_mm`).
- Tests: with a synthetic raw + synthetic channel_map (a small three-plane setup with a known pitch), put a point of known (x, y) on the three planes with a Gaussian spread (known σ) and check that the closure residual σ is √3 σ, that c is the known sum of offsets, that slices with two clusters are discarded, that ok==0 events are not used, and that a missing file returns 1. Measured red → green, and regression of the existing 5 (`test_run_metrics` 88 / `test_pulser_kernel` 237 / `test_drift_end` 89 / `test_deconv` 133 / `test_hit_residuals` 145).

## Results (2026-10-15 15:10, ELITPC, `uvw_closure.C` (`a95a494`: hit-channel condition + time window |t − tpeak| ≤ 15 cells, 263 checks green). σ/view = robust σ of the closure residual / √3, slice = 1 cell)

How the implementation evolved: (1) per-cell threshold only -> usable slices 17 % because of halos, strip count 7–9, σ/view 0.45. (2) Hit-channel condition (q ≥ 2000) -> strip count 12–18 (halos of the channels of the whole track come in). (3) Time window of ±15 cells around the channel's own peak -> usable slices 78 %, σ/view 0.30. The strip count of 11–18 is physical (a track with dip 7° enters ±24 mm within the z width of ±15 cells = ±2.9 mm) = this is the accuracy of the **2D centroid of a z slab**, not the accuracy of a single strip. The implementer stopped the amplitude-ratio idea (50 % of the peak) because it "drops the tails of real tracks" (the correct call).

### Answers
1. **The 2D (strip-plane) centroid accuracy is best at 232 ≈ 502 ns, with 0.30 mm/view**. 1014 ns gives 0.39–0.43 (the pulse is wide at 40 cells, so part of its body falls outside the ±15-cell window, and twice as many slices are discarded because of multiple clusters = this also includes the limits of the method). 70 ns gives 1.1 mm because of S/N.
2. **It does not depend on HV (250 -> 230, GEM distribution)** (0.30–0.32). The drift voltage is slightly worse at 1,000 V (0.34, more diffusion), and 1,400 V gives 0.32.
3. Strong charge dependence (Q1 0.7–0.8 -> Q4 0.40–0.45): the 2D accuracy is set by S/N. The weak-charge end (end of the track) matters.
4. Combined with 146, the "hit (slab) error": **σ_s ≈ 0.30 mm (2D, per view), σ_z ≈ 0.20 mm (1 cell)**, 232–502 ns, operating point B.
5. Limitation: a long deposit on one channel (an oblique track lying on the same channel for a long time) contributes only to the slices within ±15 cells of the peak (biased toward nearby slices with good S/N). At 1014 ns this bias is strong.
